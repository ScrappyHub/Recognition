# Recognition — brand assets

The mark is a **privacy shield** (green gradient) carrying a **padlock with a keyhole**,
on a dark rounded tile. It reads at every size from a 16 px tab favicon to a 256 px
installer icon.

## Files

| File | Use |
|---|---|
| `recognition_logo.svg` | Master vector mark (dark tile). Scale to anything. |
| `recognition_logo.png` (512) | Raster mark with tile — READMEs, store pages, social. |
| `recognition_logo_256.png` | 256 px tile raster. |
| `recognition_mark_256.png` | 256 px mark on transparent background. |
| `../browser/recognition.ico` | Multi-resolution app/exe/window icon (16–256 px). |

## Palette

| Token | Hex | Use |
|---|---|---|
| Shield top | `#7FE3B0` | gradient start |
| Shield bottom | `#1A8C63` | gradient end / keyhole |
| Lock | `#F0F7F2` | padlock body + shackle |
| Tile | `#181B22` | background tile |
| Accent (UI) | `#2B6CB0` | primary buttons |

The green shield ties to the in-app 🛡 tracker-blocking shield; the lock ties to the
identity-bound, encrypted, governed nature of the browser.
